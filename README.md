# SignBridge AI

A Computer Vision project that aims to recognize
sign language and convert it into text and speech.

## Planned Features
- Real-time hand landmark detection
- Indian Sign Language recognition
- Text-to-speech output
- Multi-person support
- Future ASL support

## Technology Stack
- Python
- OpenCV
- MediaPipe
- Scikit-learn
- Streamlit

## Project Status
Initial setup and development.
